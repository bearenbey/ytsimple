# Privacy Policy for YTSimple

Last updated: February 20, 2026

## Overview

YTSimple is a browser extension that simplifies the YouTube interface. It does not collect, store, transmit, or share any personal data.

## Data Collection

YTSimple does not collect any data. No personal information, browsing history, usage statistics, or analytics are gathered at any time.

## Data Storage

The only data stored by YTSimple is a single boolean preference (enabled or disabled) saved locally in your browser using chrome.storage.local. This data never leaves your device.

## Network Requests

YTSimple makes requests to clients1.google.com solely to fetch search autocomplete suggestions when you type in the search bar. Only your search query is sent. No cookies, authentication tokens, or personal identifiers are included in these requests.

## Third Party Services

YTSimple does not integrate with any third party analytics, advertising, or tracking services.

## Data Sharing

YTSimple does not share any data with third parties. There is no data to share.

## Changes to This Policy

If this policy is updated, the changes will be reflected in this document with an updated date.

## Contact

If you have questions about this privacy policy, you can open an issue at the project's GitHub repository.
